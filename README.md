# 🚀 Workflow Pro

A SaaS-style task management application. 

## 🔥 Features
- Authentication (login/logout)
- Protected routes
- Task CRUD (create, move, delete)
- Kanban board (drag & drop)
- Dashboard analytics
- Local storage persistence

## 🛠 Tech Stack
- React + TypeScript
- React Router
- TailwindCSS
- Vite
